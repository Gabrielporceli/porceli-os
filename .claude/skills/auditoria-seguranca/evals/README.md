# Evals da skill

Casos para medir a skill com o `skill-creator`: cada caso roda com e sem a skill, e as `expectations` são avaliadas.

A pasta `fixtures/app-vulneravel` (ainda não criada) deve ser um mini projeto Supabase + React **fictício**, com as falhas plantadas listadas nas expectations e alguns "iscas" seguras (por exemplo, a anon key no client) para medir falsos positivos.
